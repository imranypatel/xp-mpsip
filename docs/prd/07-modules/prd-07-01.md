## Feature Area 7 — Alerts & Notifications (In-App)

### Domain Entity
```csharp
public class Notification { int Id; int UserId; int? ProjectId; string TypeCode; string Title; string Body; bool IsRead; DateTime CreatedAt; }
```

### Notification Types
| TypeCode | Trigger |
|----------|---------|
| `InvitationSent` | Owner invites a partner |
| `InvitationAccepted` | Partner accepts and registers |
| `ContributionLogged` | Contribution recorded against owner's project |
| `DistributionDeclared` | Owner declares a distribution event |
| `AgreementPending` | Agreement requires partner acknowledgement |
| `MilestoneApproaching` | Task due in ≤ 3 days |
| `ProjectClosed` | Project archived |

### Application Service: `NotificationService`
| Method | Description |
|--------|-------------|
| `CreateAsync(CreateNotificationCommand)` | Insert notification; called by other services |
| `GetForUserAsync(int userId)` | Last 50 notifications, unread first |
| `MarkReadAsync(int notificationId)` | Mark one read |
| `MarkAllReadAsync(int userId)` | Mark all read |
| `GetUnreadCountAsync(int userId)` | Badge count |

### Blazor Components
| Component | Location | Description |
|-----------|----------|-------------|
| `NotificationBell.razor` | `Components/Shared/` | Icon button with unread badge; click opens popover list |
| `NotificationItem.razor` | `Components/Shared/` | Single notification row: icon, title, body, time ago, read/unread state |
| `NotificationList.razor` | `Pages/Notifications/` | Full-page notification list with "Mark all read" |

### Trigger Integration
Each service that triggers a notification calls `_notificationService.CreateAsync(...)` after its primary operation. Example in `PartnerService.InviteAsync`:
```csharp
await _notificationService.CreateAsync(new(
    UserId: ownerId,
    TypeCode: "InvitationSent",
    Title: $"Invitation sent to {email}",
    Body: $"Invitation to join project '{projectName}' sent.",
    ProjectId: projectId));
```

## P7 — UI Polish Standards

Applied across all pages after P4+P5 are complete:

| Item | Standard |
|------|---------|
| Theme | Navy primary + amber secondary (defined in prd-04-01) |
| Navigation | `MudNavMenu` with icons; active link highlighted |
| Empty states | All lists show a friendly empty state with an action button (not a blank table) |
| Loading | `MudProgressLinear` during initial data load; `MudSkeleton` for cards |
| Errors | `MudSnackbar` severity Error for failures; never raw exception messages |
| Confirmations | `MudMessageBox` for destructive actions (delete, archive, close project) |
| Forms | `DataAnnotationsValidator` + `ValidationSummary` on all forms; inline field errors |
| Responsive | `MudHidden` to hide sidebar on mobile; `MudGrid` with responsive columns |
| Accessibility | All MudBlazor ARIA attributes respected; no colour-only indicators |
