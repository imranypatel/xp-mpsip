# 08-deploy: Deployment — Summary

> **Summary PRD** for the `08-deploy` concern.

## Concern Overview
Documents step-by-step deployment runbooks for all three environments (DEV, UAT, PROD) on Windows IIS, including prerequisites, database setup, environment variable configuration, publish commands, IIS configuration, and smoke test checklists.

## PRD Index

| PRD | Title | Status | Version | Summary |
|-----|-------|--------|---------|---------|
| [prd-08-01.md](./prd-08-01.md) | Deployment Runbooks | ✅ Defined | v0.12.0 | Full IIS deployment guide: prerequisites, one-time IIS/DB setup, env var configuration, `dotnet publish` + robocopy deploy steps, `ASPNETCORE_ENVIRONMENT` setup, smoke tests, and rollback procedure for DEV/UAT/PROD. |

## At a Glance

| Item | Value |
|------|-------|
| Server | Windows Server 2019+ with IIS + .NET 10 Hosting Bundle |
| Environments | DEV (`/dev`), UAT (`/uat`), PROD (`/`) |
| App Pools | `MPSIP_DEV`, `MPSIP_UAT`, `MPSIP_PROD` (No Managed Code) |
| Databases | `MPSIP_DEV`, `MPSIP_UAT`, `MPSIP_PROD` on SQL Server |
| Config | Connection strings + SMTP credentials in Windows System Environment Variables |
| Publish | `dotnet publish -c Release -r win-x64 --self-contained false` |
| Deploy | `robocopy /MIR` to IIS physical path |
| Rollback | Restore dated backup folder via `robocopy /MIR` |
