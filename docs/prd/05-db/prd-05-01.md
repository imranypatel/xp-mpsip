> **Concern**: 05-db | **Version**: v0.7.0 | **Phase**: P2

## Goal
Define and create all database migration scripts, stored procedures, and seed data scripts for the MPSIP MVP.

## 1. Migration Scripts

Location: `src/MPSIP.Infrastructure/Database/Migrations/`  
Naming: `V{###}__{Description}.sql`  
All scripts must be **idempotent** (safe to re-run using `IF NOT EXISTS` / `IF OBJECT_ID IS NULL`).

### V001__CreateSchemaVersion.sql
```sql
IF OBJECT_ID('dbo.SchemaVersion', 'U') IS NULL
CREATE TABLE dbo.SchemaVersion (
    Version     INT           NOT NULL PRIMARY KEY,
    Description NVARCHAR(200) NOT NULL,
    AppliedAt   DATETIME2     NOT NULL DEFAULT GETUTCDATE()
);
```

## 3. Seed Scripts

Location: `src/MPSIP.Infrastructure/Database/Seeds/`

### `Seed_OpportunityKinds.sql`
```sql
IF NOT EXISTS (SELECT 1 FROM dbo.OpportunityKind WHERE Code = 'Manufacturing')
BEGIN
    INSERT INTO dbo.OpportunityKind (Code, Name) VALUES
        ('Manufacturing', 'Manufacturing'),
        ('Trading',       'Trading'),
        ('Servicing',     'Servicing');
END
```

### `Seed_ManufacturingTemplate.sql`

| Production | Manufacturing run, Quality checks |
| Quality Assurance | Final inspection, Defect resolution |
| Delivery | Packaging, Logistics, Customer handover |
| Closure | Final accounts, Partner distributions, Project review |

## 4. Migration Runner

`MPSIP.Infrastructure` includes a `DatabaseMigrator` class called at app startup:

```csharp
public class DatabaseMigrator
{
    // 1. Ensure SchemaVersion table exists
    // 2. Read all V*.sql from embedded resources (ordered by version number)
    // 3. For each script not yet in SchemaVersion: execute + insert SchemaVersion row
}
```

Called from `Program.cs` before `app.Run()`:
```csharp
using var scope = app.Services.CreateScope();
scope.ServiceProvider.GetRequiredService<DatabaseMigrator>().Run();
```
