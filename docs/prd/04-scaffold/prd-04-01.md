Create the Visual Studio solution and project structure for MPSIP, wire all dependencies, configure MudBlazor, set up environment-specific appsettings, and establish the base layouts that all feature pages will use.

## 3. Program.cs Wiring

```csharp
// MPSIP.Web/Program.cs
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddRazorComponents().AddInteractiveServerComponents();
builder.Services.AddMudServices();
builder.Services.AddHttpContextAccessor();

// Auth
builder.Services.AddAuthentication(CookieAuthenticationDefaults.AuthenticationScheme)
    .AddCookie(opts => { opts.LoginPath = "/login"; opts.ExpireTimeSpan = TimeSpan.FromHours(8); });
builder.Services.AddAuthorizationCore();
builder.Services.AddScoped<AuthenticationStateProvider, MpsipAuthStateProvider>();
builder.Services.AddCascadingAuthenticationState();

// Infrastructure (no direct reference — registered via extension method)
builder.Services.AddInfrastructure(builder.Configuration);

var app = builder.Build();
app.UseAuthentication();
app.UseAuthorization();
app.MapRazorComponents<App>().AddInteractiveServerRenderMode();
app.Run();
```

### `AddInfrastructure` extension (in MPSIP.Infrastructure)
```csharp
public static IServiceCollection AddInfrastructure(
    this IServiceCollection services, IConfiguration config)
{
    services.AddSingleton<IDbConnectionFactory>(
        new SqlConnectionFactory(config.GetConnectionString("DefaultConnection")!));
    services.AddScoped<IProjectRepository, ProjectRepository>();
    services.AddScoped<IPartnerRepository, PartnerRepository>();
    services.AddScoped<IContributionRepository, ContributionRepository>();
    services.AddScoped<IDistributionRepository, DistributionRepository>();
    services.AddScoped<ITaskRepository, TaskRepository>();
    services.AddScoped<INotificationRepository, NotificationRepository>();
    services.AddScoped<IAuthRepository, AuthRepository>();
    services.AddScoped<IEmailSender, MailKitEmailSender>();
    return services;
}
```

## 4. Base Layouts

### `MainLayout.razor`
- Top app bar: `MudAppBar` with app name, notification bell icon, user menu
- Left nav drawer: `MudNavMenu` with links per role
- Content area: `@Body` wrapped in `MudMainContent`
- `MudThemeProvider`, `MudDialogProvider`, `MudSnackbarProvider` declared once here

### `AuthLayout.razor`
- Centred `MudCard` (max-width 440px)
- App logo/name at top
- `@Body` inside card content

### `App.razor`
```razor
<Router AppAssembly="typeof(App).Assembly">
    <Found Context="routeData">
        <AuthorizeRouteView RouteData="routeData" DefaultLayout="typeof(MainLayout)">
            <NotAuthorized>
                <RedirectToLogin />
            </NotAuthorized>
        </AuthorizeRouteView>
    </Found>
    <NotFound>
        <PageTitle>Not found</PageTitle>
        <p>Page not found.</p>
    </NotFound>
</Router>
```
