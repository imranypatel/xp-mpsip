# 06-auth: Authentication — Summary

> **Summary PRD** for the `06-auth` concern.

## Concern Overview
Implements custom email/password authentication using Dapper + stored procedures (no ASP.NET Identity). Covers session cookie auth, BCrypt password hashing, invitation token flow, and the three auth Blazor pages.

## PRD Index

| PRD | Title | Status | Version | Summary |
|-----|-------|--------|---------|---------|
| [prd-06-01.md](./prd-06-01.md) | Authentication Module | ✅ Defined | v0.8.0 | Custom auth via `AppUser` + `InvitationToken` tables; BCrypt hashing; cookie sessions; custom `AuthenticationStateProvider`; Login, Register, AcceptInvitation pages. |

## At a Glance

| Item | Value |
|------|-------|
| Mechanism | Cookie auth + custom `AuthenticationStateProvider` |
| Password hashing | BCrypt (BCrypt.Net-Next) |
| Tables | `AppUser`, `InvitationToken` |
| Stored procedures | `sp_Auth_GetUserByEmail/CreateUser/CreateInvitation/RedeemInvitation/GetUserById` |
| Token TTL | 48 hours |
| Session duration | 8 hours (sliding) |
| Pages | `/login`, `/register`, `/accept-invitation?token={guid}` |
| Owner onboarding | Self-register at `/register` |
| Partner onboarding | Email invitation → `/accept-invitation` |
