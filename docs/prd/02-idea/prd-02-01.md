# Refined PRD — MVP Scope

## 1. Product Overview

**MPSIP** (Managing Partners Stakes and Incentives on a Project) is a web application that enables a single owner to manage business opportunities as projects, invite partners as stakeholders, track each partner's contributions and monetary incentives, and maintain clear progress visibility — all within a structured, contract-backed lifecycle.

**MVP scope**: Manufacturing opportunity kind, single-owner model, web platform.

---

## 2. Users & Roles

| Role | Description |
|------|-------------|
| **Owner** | Creates and manages projects; invites partners; has full access |
| **Investor** | Financial stakeholder; provides capital; receives profit share |
| **Domain Expert** | Provides specialist knowledge; receives agreed monetary incentive |
| **Consultant** | Advisory role; receives agreed monetary incentive |
| **Contractor** | Executes specific deliverables; receives agreed payment |
| **Builder** | Constructs physical/product elements; receives agreed payment |
| **Developer** | Technical implementation; receives agreed payment |
| **Labour** | Operational/physical work; receives agreed wage/incentive |

> A partner can hold one or more roles in a project. Roles determine stake percentage and incentive structure.

---

## 3. Core Features (MVP)

### 3.1 Authentication & Onboarding
- Owner registers via email/password
- Partners are invited by the owner via email link
- Partner clicks link → self-registers → joins the project

### 3.2 Project Management
- Create a Manufacturing project with:
  - Name, description, opportunity kind (Manufacturing)
  - Start date and expected completion date
  - Risk declarations and contingency provisions
- Apply the built-in **Manufacturing starter template** (pre-populated processes, resources, workflow stages)
- Track project lifecycle: Phase → Stage → Status → State

### 3.3 Partner & Stake Management
- Invite partners by email; assign one or more roles per partner per project
- Define each partner's stake (percentage-based, monetary)
- Record each partner's agreement via **digital acknowledgement** (checkbox + e-signature within the platform)
- Agreement captures: expected contributions, incentive terms, risk acceptance

### 3.4 Contribution Tracking
- Owner and partners can both log contributions against tasks/sub-tasks
- Contribution types: Man (time/effort), Material (goods/inventory), Money (cash outlay)
- Each contribution entry: date, contributor, type, description, amount/quantity

### 3.5 Incentive & Distribution Management
- Monetary incentives only (revenue/profit share)
- Owner declares distribution events (e.g. milestone payout, project close-out)
- System calculates each partner's share based on stake and agreed terms
- Distribution is recorded with date, amount, and acknowledgement by recipient

### 3.6 Workflow & Task Management
- Tasks and sub-tasks derived from the Manufacturing starter template
- Assign resources (Man, Material, Money) to tasks/sub-tasks
- Track status of each task: Not Started → In Progress → Blocked → Completed

### 3.7 Dashboard & Reporting
- Owner dashboard: all projects summary cards (status, % complete, next milestone, total contributions, distributions pending)
- Partner dashboard: projects I'm involved in, my contributions, my upcoming incentives
- Per-project view: lifecycle progress, partner stakes, contribution log, distribution history

### 3.8 Alerts & Notifications (In-App)
- Contribution due / overdue alerts
- Distribution milestone reached
- Project milestone approaching
- New partner invitation accepted
- Contract acknowledgement pending

### 3.9 Project Closure
- Owner triggers project closure workflow
- System prompts for: final distribution event, partner feedback collection, closure summary
- Project archived with full audit trail

---

## 4. Manufacturing Starter Template

Pre-built template covering:
- **Phases**: Ideation → Planning → Procurement → Production → Quality Assurance → Delivery → Closure
- **Default roles**: Owner, Investor, Contractor, Builder, Labour
- **Resource types**: Man (hours), Material (units/kg/etc.), Money (currency)
- **Default tasks** per phase (owner can customise)

---

## 5. Out of Scope for MVP

- Trading and Servicing opportunity kinds
- Multi-tenant SaaS (multiple organisations)
- Email / SMS notifications
- Mobile app
- PDF contract generation
- Additional templates beyond the Manufacturing starter
- Equity/ownership stakes (non-monetary incentives)
- External integrations (accounting, ERP, payment gateways)

---

## 6. Non-Functional Requirements

| Concern | Requirement |
|---------|-------------|
| Platform | Web application (responsive, modern browser) |
| Auth | Secure email/password auth; invitation tokens expire after 48 hours |
| Data | All project data persisted; full audit trail for contributions and distributions |
| Access control | Partners see only the projects they are invited to; role-scoped views |
| Scalability | Single-owner MVP; architecture should not preclude future multi-tenancy |
