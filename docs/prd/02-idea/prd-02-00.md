## Product Vision (One-liner)

> MPSIP is a web application that lets a project owner manage Manufacturing opportunities as structured projects — inviting partners, tracking contributions, distributing monetary incentives, and maintaining full lifecycle visibility with digital agreements.

---

## MVP Scope at a Glance

| Dimension | MVP Decision |
|-----------|-------------|
| User model | Single-owner; multi-tenant SaaS planned for later |
| Opportunity kind | Manufacturing only |
| Template | One built-in Manufacturing starter template |
| Incentives | Monetary only (revenue/profit share) |
| Contributions | Logged by owner and/or partners |
| Notifications | In-app only |
| Platform | Web application |
| Partner onboarding | Email invitation + sign-up link |
| Reporting | Dashboard with project summary cards + key metrics |
| Contracts | Digital acknowledgement (checkbox + e-signature) |

---

## Partner Roles

Owner · Investor · Domain Expert · Consultant · Contractor · Builder · Developer · Labour

---

## Out of Scope for MVP

- Trading and Servicing opportunity kinds
- Multi-tenant SaaS
- Email/SMS notifications, mobile app
- PDF contract generation
- Additional templates, equity stakes, external integrations
